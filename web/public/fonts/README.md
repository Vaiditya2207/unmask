# Bundled interface fonts

These 13 WOFF2 files are the exact bytes emitted by the pinned Next.js 16.4.2 Google-font loader for this interface: Bricolage Grotesque (variable weight 200–800 with the `opsz` axis) and IBM Plex Mono (400/500). Their combined size is 186,080 bytes. No font was modified or substituted.

They come from the redesign's two `next/font/google` calls (commit cda6fd8): `Bricolage_Grotesque({ subsets: ["latin"], axes: ["opsz"], variable: "--font-sans", display: "swap" })` and `IBM_Plex_Mono({ subsets: ["latin"], weight: ["400", "500"], variable: "--font-mono", display: "swap" })`. Those calls were restored in a scratch copy of revision 4e80590 and built with both Turbopack and webpack. Both builds emitted the same 13 files. The loader made two CSS requests and fetched 13 font URLs. Each URL was downloaded again and its SHA-256 digest matched an emitted file.

The [manifest](manifest.json) records the two upstream CSS requests, each font's gstatic URL, byte size and SHA-256 digest, two license sources with original and bundled digests, and all 15 face declarations. Each font filename is its full content SHA-256. The upstream CSS endpoints are provenance, not build dependencies.

[The stylesheet](../../app/fonts.css) keeps all 13 real face declarations exactly as the loader emitted them. That includes Unicode ranges, the variable weight range and `font-stretch`. It also keeps the two fallback metric faces and defines `--font-sans` and `--font-mono` on `:root` with the loader's values. Bricolage Grotesque has 3 faces (Vietnamese, Latin Extended, Latin). IBM Plex Mono has 5 faces per weight (Cyrillic Extended, Cyrillic, Vietnamese, Latin Extended, Latin). The `subsets: ["latin"]` option chose which files the loader marked for preloading. It did not remove other scripts from the Google CSS, so those subsets stay bundled. The loader marked three Latin files for preloading. The layout preloads the two needed for first paint: Bricolage Grotesque Latin and IBM Plex Mono 400 Latin. IBM Plex Mono 500 Latin loads when it is used.

This removes build-time Google Fonts requests and the pinned loader's assumption that every successful download URL ends in a font filename extension. All assets are served from this application's `/fonts/` path. Content-addressed WOFF2 URLs have immutable one-year cache headers. The Docker image explicitly copies `public/` into its runtime stage; no package or toolchain pins changed.

License text uses LF line endings with trailing whitespace removed; original source and bundled text hashes are recorded separately. Each family retains its upstream copyright notice and SIL Open Font License 1.1: [Bricolage Grotesque](bricolagegrotesque-OFL.txt) and [IBM Plex Mono](ibmplexmono-OFL.txt). These font files remain under their included licenses, separate from the application's license.

`npm test` in `web/` validates every binary hash/header/size, the exact face properties, coverage, licenses and preload/packaging contract. To update fonts, obtain the intended upstream bytes, review their notices, update the hash-addressed files and provenance/face records together, and verify a fresh build without Google network access. Do not replace this with production font mocks or dependency-file patches.
