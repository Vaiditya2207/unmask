# Project report

IEEE conference-format report for UNMASK (Team Cappybara, Hacktoberfest 2026).

- `unmask-report.tex` — editable LaTeX source
- `unmask-report.pdf` — compiled copy

## Edit names and roles

Open `unmask-report.tex` and change the block marked `EDIT HERE` near the top.
Each author has a name, a role shown under the name, and a short description used
in Appendix B. The department, institute and report line are set there too.

## Build

With [Tectonic](https://tectonic-typesetting.github.io):

```bash
tectonic unmask-report.tex
```

Or upload `unmask-report.tex` to Overleaf (compiler: pdfLaTeX or XeLaTeX).
