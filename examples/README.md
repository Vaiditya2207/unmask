# Examples

The hackathon requires representative inputs and actual outputs produced by the
tool. This directory is reserved for those examples; the analyzer has not been
implemented, so no analysis output is claimed yet.

For each working example, add a named directory containing:

- `README.md` with the exact command, prerequisites, package version, source
  revision, and relevant model/runtime details.
- `input/` with public sample inputs and any required provenance or license
  information.
- `output/` with the actual output of the documented command.

Keep examples small and reproducible. Label deliberately modified fixtures as
synthetic. Include legitimate packaging differences as well as suspicious
changes. Store unresolved results honestly; do not replace them with invented
verdicts. Preserve input and output bytes when running formatters.
