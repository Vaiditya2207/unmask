# Synthetic partial advisory decision

The input is deliberately synthetic: a made-up package and malware advisory ID.
It does not assert a real package is malicious. There is no artifact report and
the advisory lookup is incomplete, so the actual output preserves incomplete
assessment while retaining the positive malware blocker.

From repository root, with pinned Node.js 24.22.2 and `npm ci --ignore-scripts`:

```sh
node --input-type=module -e 'import {readFileSync} from "node:fs"; import {evaluateGuardDecision} from "./src/core/guard-policy.mjs"; console.log(JSON.stringify(evaluateGuardDecision(JSON.parse(readFileSync("examples/guard-decision/input/assessment.json", "utf8"))), null, 2));' > examples/guard-decision/output/decision.json
```

Source base: `0ccc70f534c2be0b2749e39ee1977935a4bfd277`, plus the guard-decision
feature on the current branch. Package version 0.1.2. This command uses only the
local pure decision function, makes no network/model calls and executes no
package contents. The committed output was generated by that command.
