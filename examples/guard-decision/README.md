# Synthetic partial advisory decision

The input is deliberately synthetic: a made-up package and malware advisory ID.
It does not assert a real package is malicious. There is no artifact report and
the advisory lookup is incomplete, so the actual output preserves incomplete
assessment while retaining the positive malware blocker.

From repository root, with pinned Node.js 24.22.2 and `npm ci --ignore-scripts`:

```sh
node --input-type=module -e 'import {readFileSync} from "node:fs"; import {evaluateGuardDecision} from "./src/core/guard-policy.mjs"; console.log(JSON.stringify(evaluateGuardDecision(JSON.parse(readFileSync("examples/guard-decision/input/assessment.json", "utf8"))), null, 2));' > examples/guard-decision/output/decision.json
```

Source base: `0ccc70f534c2be0b2749e39ee1977935a4bfd277`, plus the guard-decision
feature on the current branch. Package version 0.1.2. This command uses only the
local pure decision function, makes no network/model calls and executes no
package contents. The committed output was generated by that command.

To compare profile handling using the same synthetic partial input:

```sh
node --input-type=module -e 'import {readFileSync} from "node:fs"; import {evaluateGuardDecision} from "./src/core/guard-policy.mjs"; const input=JSON.parse(readFileSync("examples/guard-decision/input/assessment.json", "utf8")); console.log(JSON.stringify(["strict","balanced","audit"].map(profile=>evaluateGuardDecision(input,{profile})),null,2));' > examples/guard-decision/output/profiles.json
```

The profiles output is generated locally. All retain the observed blocker and
incomplete assessment; only audit explicitly allows continuation without
claiming safety. The default profile is strict.

The additional `input/historical-advisories.json` contains public normalized OSV
lookup receipts for three historical incidents, captured 2026-10-31 by the
existing advisory helper. Their sources and exact package/version classification
are documented in `docs/guard-decisions.md`. No artifact or target code is
included or executed. Reproduce the historical output locally:

```sh
node --input-type=module -e 'import {readFileSync} from "node:fs"; import {evaluateGuardDecision} from "./src/core/guard-policy.mjs"; const checks=JSON.parse(readFileSync("examples/guard-decision/input/historical-advisories.json","utf8")); console.log(JSON.stringify(checks.map(vulnerabilityCheck=>evaluateGuardDecision({nameAtExactVersion:vulnerabilityCheck.package.name+"@"+vulnerabilityCheck.package.version,vulnerabilityCheck},{profile:"balanced"})),null,2));' > examples/guard-decision/output/historical-decisions.json
```

These receipts exercise identity recognition without MAL aliases. Artifact and
source assessment remain incomplete. This local replay does not establish
normal hosted-route recovery for removed versions; that requires S01 integration.
